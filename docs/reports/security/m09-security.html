4. Notas do auditor

  • Local security-focused regression report, not an advisory/CVE scan or native-provider acceptance. No dedicated SAST/SCA scanner was run in M09. Use m09-validation.json for measured final checks.
  • Update integrity does not authenticate a publisher. Regular matching native artifacts only; version probes have a five-second deadline and output bounds. Prefix and destination symlinks/reparse points are rejected. Unknown binaries, mismatched checksums and tampered rollback generations are preserved/refused.
  • Snapshot and restore verify engine/workbench schema, complete file inventory, hashes, sealed SQLite databases and integrity. SQLite backup API includes WAL. Exclusive maintenance ownership excludes Store writers, native reservations and workbench sessions; supervisors must be stopped.
  • Restore only publishes a verified complete copy to a fresh directory. Future schema versions stay unreadable even with matching hashes. Historical checkpoints grant no new acceptance. No incompatible migration was introduced.
  • Existing secure RNG, native owned-group shutdown, credential redaction, sensitive context exclusions and cached-input accounting remain covered by earlier-stage regression tests. Model/account, permission and prompt policy were not weakened.
  • Assumption: installation/snapshot parent paths and metadata are owned by the operator. This does not defend against a malicious OS user with concurrent write access to parents or a caller who deliberately substitutes both data and its declared checksum. No encryption/signature guarantee is claimed. Linux and Windows still require native pilots.
