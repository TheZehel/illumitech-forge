# F066 — Agent experience and portable skill

Deliver one compatible minor candidate covering first-run diagnosis, command discovery,
actionable blockers, durable continuity and a portable Illumitech Forge skill.
Codex remains the executor. Codex/VS Code and Cursor are installation targets, not new
executor or platform acceptance claims. Installation is guided, never implicit.

- AC1: A clean user can distinguish missing Git/project/client/authentication, installation
  conflicts and unverified platform support, then follow a no-agent demo or a Codex feature.
- AC2: `contracts [--command "PATH"]` describes real public parser arguments and reviewed
  effects. Examples parse against the same parser; hidden commands are excluded.
- AC3: Covered failures expose typed diagnostics with stable code, cause, blocked operation
  and actions. Existing fields and parse errors retain their contracts. Unclassified errors
  explicitly disclose missing diagnosis; no string-based error classification.
- AC4: Workflow, Feature and QA status expose a common read-only continuity projection.
  Active/uncertain processes never yield automatic replay; stale evidence never passes.
- AC5: The portable skill uses capabilities and version checks, routes to maintained
  references, and preserves exact scope consent, native permissions and human acceptance.
- AC6: Versioned plugin and skill archives are reproducible, checked and accompanied by
  checksums. Host pilots and directory submissions remain separately reported.

No telemetry, destructive migration, new executor, global configuration change, push,
release upload or directory submission is part of implementation.
