# illumitech-forge-domain 1.9.1

Domain contracts, evidence and durable execution state for
[Illumitech Forge](https://github.com/TheZehel/illumitech-forge): a toolkit to plan, execute,
verify and resume development with external checks.

For installation and end-user workflows, use
[illumitech-forge-cli 1.9.1](https://crates.io/crates/illumitech-forge-cli/1.9.1).
See the [matching release](https://github.com/TheZehel/illumitech-forge/releases/tag/v1.9.1)
for notes and checksums.

Release-publication intent is recorded separately from draft PRs; existing state and manifest schemas remain version 1.

MIT licensed. LICENSE, THIRD_PARTY_NOTICES and the dependency inventory accompany this
package. External agent clients and optional ai-memory are not bundled.


## Duration messages and visual identity

The CLI and Workbench communicate in Portuguese with days, hours, minutes and seconds,
using natural singular/plural and retaining range bounds (for example,
`10 minutos e 30 segundos`); machine-readable estimates retain seconds. The IllumiTech presentation
uses the Construct Companion cream/graphite/orange palette. See the release notes and checksums for distribution and validation evidence.
